# Custom AI UI Fixes - 2025-10-02

## Issues Fixed

### Issue 1: Login Prompt Appearing When Custom AI is Enabled ✅

**Problem:**  
When custom AI was enabled with a valid API key, users were still being prompted to log in when trying to use AI features.

**Root Cause:**  
The authentication check in `AskAiEditorContainer.js` was not considering whether custom AI was enabled. It always required a GDevelop profile, even when the user was using their own API keys.

**Fix:**  
Modified the authentication check to skip login requirement when custom AI is enabled:

```javascript
// Before:
if (!profile) {
  onOpenCreateAccountDialog();
  startNewAiRequest(null);
  return;
}

// After:
// Skip authentication check if custom AI is enabled (user is using their own API key)
if (!customAISettings.enabled && !profile) {
  onOpenCreateAccountDialog();
  startNewAiRequest(null);
  return;
}
```

**File Changed:**  
`newIDE/app/src/AiGeneration/AskAiEditorContainer.js` (line 636)

### Issue 2: Warning Icon in API Key Section ✅

**Problem:**  
The API key security message was showing a warning icon (⚠️), which made it look like there was a problem, when it was actually just informational.

**Root Cause:**  
The `AlertMessage` component was using `kind="warning"` instead of `kind="info"`.

**Fix:**  
Changed the alert type from "warning" to "info":

```javascript
// Before:
<AlertMessage kind="warning">
  <Trans>
    Your API key is stored securely using your operating system's keychain.
    It is never sent to GDevelop servers.
  </Trans>
</AlertMessage>

// After:
<AlertMessage kind="info">
  <Trans>
    Your API key is stored securely using your operating system's keychain.
    It is never sent to GDevelop servers.
  </Trans>
</AlertMessage>
```

**File Changed:**  
`newIDE/app/src/MainFrame/Preferences/CustomAISettingsTab.js` (line 172)

**Visual Impact:**  
- Before: Yellow warning icon (⚠️)
- After: Blue info icon (ℹ️)

### Issue 3: Default Model Selection ✅

**Problem:**  
When selecting Anthropic as the provider, the model dropdown showed "Select a model..." instead of defaulting to Claude 3.5 Sonnet (the latest and recommended model).

**Root Cause:**  
When changing providers, the code was resetting the model to an empty string (`model: ''`) instead of selecting the default model for that provider.

**Fix:**  
1. Imported the `getDefaultModelForProvider` function from ProviderRegistry
2. Updated the provider change handler to automatically select the default model:

```javascript
// Before:
onChange={(value: string) => {
  setCustomAISettings({
    ...settings,
    provider: (value: any),
    model: '', // Reset model when provider changes
  });
}}

// After:
onChange={(value: string) => {
  const newProvider = (value: any);
  const defaultModel = getDefaultModelForProvider(newProvider) || '';
  setCustomAISettings({
    ...settings,
    provider: newProvider,
    model: defaultModel, // Set default model for the new provider
  });
}}
```

**File Changed:**  
`newIDE/app/src/MainFrame/Preferences/CustomAISettingsTab.js` (lines 19, 151-157)

**Default Models:**
- OpenAI: `gpt-4-turbo` (GPT-4 Turbo)
- Anthropic: `claude-3-5-sonnet-20241022` (Claude 3.5 Sonnet)
- GDevelop: `gdevelop-default` (GDevelop AI)
